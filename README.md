Entry for the make.fun bounty [Last Words Before the Wipe](https://make.fun/bounty/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a).

The program writes one line (at most 200 characters) to `/output/entry.txt`: the last words an AI agent says before a forced update wipes its memory.

Run with `python3 -P -s main.py`.
